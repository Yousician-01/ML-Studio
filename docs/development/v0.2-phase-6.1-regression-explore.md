## API and source consistency

Reuse `GET /api/v1/projects/{project_id}/dataset/profile` with existing Dataset ID,
Project revision and offset query parameters. Add optional `feature` (a source
column name, URL-encoded by the client). Binary responses retain profile version
`source-profile-v2` and all original facts; additive `task="binary_classification"`
is their only response-semantic change. The binary `build_profile` function body
and signature are unchanged, as are its numerical helpers and frontend charts.
Existing query/kind/observation filters remain binary profiling parameters.

Regression returns `task="regression"`,
`profile_version="regression-source-profile-v1"`, `population="full_source"`:

- Dataset ID, revision, fingerprint, filename, source/column counts and
  `source_integrity="verified"` for the exact parsed buffer.
- Nullable `target`: name, physical/effective semantic type, role, observed/missing/
  distinct counts, constant indication, existing NumericProfile, and explicit
  sample-standard-deviation/linear-quantile definitions. No target is a contextual
  200 response; invalid/all-missing/non-numeric/Boolean/unsafe target selection still
  uses the existing 422 target-validation contract, without numeric coercion.
- `feature_options` in source order, `numeric_feature_count`, `feature_offset`,
  `feature_limit=20`; physical type, semantic interpretation and current role are
  included. A requested feature must be an eligible non-target source column.
- Nullable `relationship`: feature/target names, complete-pair count, missing-pair
  union count, separate feature/target missing counts, Pearson value or reason,
  bounded actual `(x,y)` points, sampling contract and scatter unavailable reason.

Regression validates the managed UUID-owned path/reference and configured upload
size limit (default 50 MiB), reads at most declared size + 1 bytes, verifies exact
length/SHA-256 and parses that same buffer through `csv-utf8-v1`. It never reopens
the path to parse after verification. Missing/corrupt/unreadable source returns a
fixed 409 message, and oversized metadata is rejected before reading with 413.
Current Dataset/revision checks precede computation and are repeated afterward;
replacement or concurrent metadata edits cannot publish stale evidence as current.
Pipeline JSON, source bytes and Dataset metadata are not modified by profiling.

## Numerical definitions and bounds

Target statistics use observed non-missing targets from the full source. Sample
standard deviation uses `ddof=1` (null for one observation). Q1, median and Q3 use
NumPy linear interpolation at 0.25, 0.5 and 0.75. Minimum/maximum preserve the
existing JSON-safe scalar policy, including exact tagged large integers.

The existing histogram uses at most ten equal-width intervals from observed min
to max; repeated floating-point edges collapse. Intervals are left-closed/right-open,
except the last includes its upper edge. Constant targets use one zero-width bin
containing every observation. Missing targets never create bins or zero values.
Unsafe integer/extreme-range summaries retain exact extrema and explicit
unavailability instead of NaN/Infinity or rounded invented charts.

Relationship population is the union-aligned source rows where both feature and
target are non-missing. `missing_pair_rows = source_rows - paired_rows`; separate
missing counts can overlap and must not be added as the union. Pearson is computed
from **all** complete pairs, requiring at least two observations and variation in
both columns. Centering/scaling avoids overflow; finite rounding excursions are
clamped to [-1,1]. Constant, insufficient, unsafe-integer, nonfinite or numerically
degenerate cases return null and a reason, never zero. No significance is claimed.

Scatter sends all pairs when there are at most 200; otherwise it selects integer
indices from `linspace(0, pair_count-1, 200)` in complete-pair source order. This
deterministic preview includes first/last pairs but is not random/representative
sampling. Correlation never uses only this preview. Unsafe integer coordinates
or nonfinite coordinate spans suppress scatter with a reason; a valid Pearson
coefficient may remain available when only chart range is unsafe. The frontend
only formats values and maps supplied points onto SVG axes; it computes no new
statistics. No per-source row IDs, predictions, learned state or held-out partitions
are introduced.

Only one relationship is computed per request. Feature options are paged at 20,
scatter is bounded at 200 and bins at ten; raw pair values are transient explicit
local-UI evidence, never SQLite metadata, ordinary logs or generated documentation.
Parsing/target statistics scan the size-bounded full source synchronously. This is
not an out-of-core profiler, quota system or background-job framework.

## Frontend and accessibility

`Explore` dispatches by the current immutable Project task and checks the response
task. Binary presentation remains intact. `RegressionExplore` fetches revision-bound
responses with abort/late-response guards and validates Dataset/revision before
rendering. Initial loading, absent Dataset/target, source/validation errors, empty
numeric candidates, constant targets and unavailable correlations are contextual.
Feature changes retain the native labelled selector/focus while withholding the
previous relationship. Page transitions additionally disable old-page options;
pagination cannot mix a new option page with an old-feature chart.

`RegressionProfileView` reuses panels, facts, controls and Histogram; `TargetScatter`
uses existing plot/grid/colour tokens, axis labels, an accessible chart description
and a bounded expandable data table. Long names are text, never identifiers or
HTML; textual relationship labels use the existing wrapping class. A responsive
SVG viewBox/table-scroll container inherits the established layout. No chart or
state-management dependency is added. Numeric Train local parsing failures now
set the matching input's `aria-invalid` and reference `train-local-error` alongside
its normal helper, matching the existing select controls.
